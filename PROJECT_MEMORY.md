# CalcRate — память и спецификация проекта

Версия документа: 2026.11.17.1.
Основание: исходники и хронологическая спецификация,
переданные пользователем 17.11.2026, до V46 от 15.11.2026.

## 1. Статус и приоритет источников

- Сейчас актуальны веб/PWA и Windows-оболочка CalcRate.pyw.
- Проект первоначально создавался в Claude для Android,
  затем адаптировался под iPhone Air.
- SwiftUI, старые макеты Calc++/CalcPlus и Android — история,
  а не текущая целевая реализация.
- Приоритет: новое прямое решение пользователя; затем последнее
  датированное согласованное требование; затем более старое.
- Код показывает реализацию, но сам по себе не отменяет требования.
- Конфликт кода и спецификации фиксировать явно.
- Не восстанавливать отсутствующие требования по догадкам.
- Перед изменением читать этот файл и актуальные исходники.
- Этот документ не подтверждает прохождение испытаний.

## 2. Архитектура

- Статическое приложение без обязательной сборки на сервере.
- Хостинг — GitHub Pages, репозиторий calcrate.
- Основные файлы в корне:
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, icon-maskable-512.png,
  apple-touch-icon.png.
- Пути относительные: приложение должно работать в /calcrate/.
- Веб-версия и Windows-оболочка используют один сайт.
- Windows: pywebview и WebView2, отдельный профиль браузера.
- Нельзя обещать наличие WebView2 на любой Windows.
- Настройка браузерного окна не гарантирует размер 320x532.
- Собственное окно 320x532 реализуется Windows-оболочкой.
- Данные браузера, установленной PWA, разных устройств и
  Windows-профиля нельзя считать автоматически общими.
- Серверной синхронизации в переданном коде нет.

## 3. Интерфейс: не менять без согласования

Четыре вкладки:
Калькулятор / Переменные / Функции / Конвертер.

Настройки калькулятора — шестерёнка слева перед ENG.
Справа на табло — вставка из буфера в место курсора.
Отдельную вкладку настроек не возвращать.

Основная клавиатура V46, 15.11.2026:

| =   | ◀ | ▶ | C | ⌫ |
| 7   | 8 | 9 | ÷ | () |
| 4   | 5 | 6 | × | M |
| 1   | 2 | 3 | − | ƒ(x) |
| +/− | 0 | . | + | История |

- ENG не переставлять.
- () влево — обернуть выражение.
- M вверх — M+, вниз — M−.
- C вверх — MC; ⌫ вверх — CE.
- ◀/▶ вверх — начало/конец.
- История вверх/вниз — отмена/повтор.
- Клавиатуры правки значений и формул соответствуют основной.
- Готово занимает два ряда вместо ƒ(x) и Истории.
- У Готово вверх — выбор кода валюты.
- Не заменять иконку новой картинкой без решения пользователя.
- В сборке используется предоставленное изображение.

## 4. Калькулятор и редактирование

- Переменные и пользовательские функции сохраняются.
- Имена поддерживают Unicode-буквы; код также допускает "_".
- Идентификатор с цифрой в конце остаётся одним именем.
- Курсор не должен вставать внутрь имени.
- Тап ставит курсор к ближайшей допустимой границе.
- Удержание 0.4 с — лупа 128x56, увеличение 1.25.
- После отпускания — капсула Вставить над строкой.
- Свайп по выражению влево — ⌫, вправо — C.
- ENG, настройки, вкладки и ввод закрывают капсулу.
- Повторный знак заменяет предыдущий.
- Отрицательное число после ×/÷ вводится через +/−.
- История открывается на Недавних.
- Недавние и Сохранённые очищаются независимо.
- При перезапуске курсор в конце; цифра продолжает выражение.
- Недописанные новые строки не должны становиться готовыми данными.
- Переименование обновляет ссылки и корректирует позицию курсора.
- Аргументы функций следуют формуле, учитывая ручную правку.
- Коды валют не становятся аргументами функций.
- Выключенное "Считать на лету": перемещение курсора
  не пересчитывает и не стирает результат.
- = и вызов памяти вставляют показанное число.
- Числовой движок использует JavaScript Number:
  произвольная десятичная точность не гарантируется.
- Дробный факториал рассчитывается через Gamma(x+1).
- Промежуточные вычисления и численные методы требуют
  отдельных тестов; нельзя называть все операции точными.

## 5. Формат чисел

- Точность по умолчанию 2.
- За нулями по умолчанию 6.
- Миграция настроек revision 3 от 13.11.2026 сохраняется.
- За нулями: Выкл либо значение больше Точности, до 15.
- При Точности 0 расширение За нулями не действует.
- Примеры при 2/6:
  1234.56789 -> 1234.57
  0.0023666 -> 0.002367
  0.000023456 -> 0.000023
  12.0034 -> 12.0034
  0.000000235 -> 2.35E−7
- Округление половин — от нуля.
- Пользовательский разделитель не должен конфликтовать
  с буквами, цифрами и математическим синтаксисом.
- Разделители удаляются при переносе числа в выражение.
- Старые записи истории с нестандартным разделителем
  требуют осторожности после его смены.

## 6. Общие настройки

- Язык, разделитель, тема, фон, вибрация,
  контраст и Не гасить экран общие с конвертером.
- Три темы: чёрная, графит, светлая.
- Фон: 10 вариантов, включая отсутствие цвета.
- Насыщенность 5–100%.
- Фон подмешивается на p%, остальные поверхности на 0.8*p%.
- Панели настроек сохраняют открытость между вкладками.
- Более позднее требование 23.10 говорит о закрытии кнопкой Назад.
- Не добавлять свайп закрытия только на основании старого текста.
- Не гасить экран: часы 0–99; 0/пусто — без лимита бездействия.
- При N>0 отсчёт от последнего взаимодействия в приложении.
- Wake Lock зависит от браузера и разрешений ОС.
- Прямой Taptic Engine веб-странице не гарантирован.
- Приём со скрытым switch требует проверки на настоящем iPhone.
- Нельзя обещать его работу по номеру iOS без испытания.

## 7. Конвертер

- Круговое листание столов, три панели: предыдущая/текущая/следующая.
- Добавление, переименование, удаление с подтверждением,
  изменение порядка столов.
- Валюты: добавление с поиском, удаление свайпом, перестановка.
- Закреплённая валюта остаётся после перезапуска.
- Пустой стол сохраняется.
- Первая добавленная в пустой стол валюта становится вводом.
- Удаление валюты ввода закрывает правку суммы.
- Удержание карточки 1 с копирует значение.
- Удержание области флага 0.5 с закрепляет валюту.
- На iPhone запись в буфер повторяется при отпускании.
- Переключение вкладки не должно давать скрытому
  конвертеру перехватывать физическую клавиатуру.
- Состояние его открытой клавиатуры между вкладками сохраняется.

Первый запуск:
- Путешествие: USD/EUR, база USD, сумма 100,
  комиссия 2%, режим прибавления, локальное feeOn=true.
- Работа: USD/EUR, база EUR, сумма 500,
  feeOn=false, комиссия 1%, режим вычитания.
- Общий переключатель комиссии feeShow=false.
- Пресеты 0/1/2/5%.

Курсы:
- https://open.er-api.com/v6/latest/USD
- Один запрос со всеми курсами, свежесть 6 часов.
- Последние успешные курсы сохраняются.
- Без сети: сохранённые, иначе встроенные.
- Встроенные значения не считать актуальными котировками.
- Фиксированное число "166" — историческое требование,
  а не проверенный текущий ответ API.
- Нынешний код имеет фиксированный каталог кодов:
  новые коды API автоматически в интерфейс не добавляются.
- Не удалять валюты со столов при изменениях каталога автоматически.
- Флаги SVG, без эмодзи; упрощённые геометрические рисунки.
- CNH использует флаг CNY, но это не требование равенства курсов.
- XAF Камерун; XOF Сенегал; XCD Сент-Китс и Невис;
  XPF Франция; XDR глобус; ANG/XCG Кюрасао.
- 20 популярных валют первыми, остальные по локальному имени.
- Поиск: код, локальное и английское имя, без влияния ударений.
- В формуле код валюты означает число её единиц за 1 USD.

## 8. iPhone и компьютер

- Эталон старого макета iPhone Air: 420x912,
  верхняя безопасная область 68.
- Эти размеры не считать универсальными для всех устройств.
- Фактическую safe-area и высоту проверять на устройстве.
- Сохранён существующий обход высоты standalone через screen.height:
  его правильность в этой сборке не подтверждена.
- На телефоне одно приложение без рамки телефона,
  искусственных часов, Dynamic Island и home indicator.
- На ПК компактный вид и сворачиваемое нижнее меню.
- Масштабирование указателей, лупа, жесты и перетаскивание
  должны проверяться при масштабе Windows 100/125/150%.
- Глобальные переопределения DOM-геометрии пока сохранены:
  это технический риск, а не рекомендуемая новая архитектура.
- Масштаб страницы пользователем сейчас ограничен;
  влияние на доступность требует отдельного решения.

## 9. Хранилище: сохранять совместимость

Не переименовывать без миграции:
- calcrate.web.calc
- calcrate.web.conv
- calcrate.web.rates
- calcrate.web.tab

Не очищать localStorage, профиль WebView или кэш пользовательских
данных ради обновления приложения.
Service worker хранит файлы приложения, не заменяет резервную копию.
Браузер/ОС могут удалить локальное хранилище.
Резервное копирование/экспорт данных в этой сборке не добавлены.

Неограниченные числа теперь записываются с явным JSON-маркером.
Старые Infinity, уже превращённые прежним кодом в null,
автоматически восстановить нельзя.
Откат на старый код после новой записи данных не проверен.

## 11. Нерешённые противоречия

До прямого решения пользователя сохраняется веб-код:
1. Клавиша конвертера 000; старое описание говорит 00.
2. Вкладки доступны с открытой клавиатурой конвертера;
   старое описание требует их скрывать.
3. В настройках конвертера остаётся autoTop,
   несмотря на старое требование "только комиссия".

## 12. Проверки перед выпуском

Автоматические, если установлен Node.js:
- Синтаксис всех встроенных скриптов и sw.js.
- Базовая арифметика и приоритеты.
- Проценты, факториал, округление.
- Точность/За нулями на согласованных примерах.
- Нормализация вставки.
- Отказ от небезопасного диапазона sum.
- ncr(200,2).
- Сохранение неограниченных чисел.

Обязательные ручные, пока не подтверждены:
- Первый запуск на настоящем iPhone Air.
- Установка на экран Домой через доступное меню браузера.
- Верх/низ экрана, открытие системной клавиатуры, её закрытие.
- Обе ориентации: manifest orientation — пожелание браузеру,
  а не гарантия блокировки ориентации в iOS.
- Все вкладки, ENG, настройки, история, буфер, лупа.
- Переменные и функции: создание/правка/переименование/удаление.
- Столы: листание/перестановка/пустой стол/удаление валюты ввода.
- Скрытая клавиатура конвертера не мешает калькулятору.
- Комиссия, пресеты, все темы, фон, языки и контраст.
- Реальная работа вибрации и Wake Lock.
- Перезапуск, сохранение данных, обновление без их потери.
- Офлайн после первого успешного кэширования.
- Обновление на действующем GitHub Pages, затем запуск офлайн.
- Windows-оболочка и масштабы 100/125/150%.
- Маска иконки и внешний вид apple-touch-icon.
- Условия использования поставщика курсов отдельно не проверены.

## 13. Правила дальнейших изменений

- Не объявлять сборку проверенной без отчёта о тестах.
- Не возвращать старую раскладку.
- Не заменять функциональность упрощённым новым калькулятором.
- Не переписывать весь index.html ради локального исправления.
- Каждое изменение: причина, файлы, совместимость данных,
  автоматические и ручные проверки.
- Сначала сохранять рабочую контрольную версию.
- Полный аудит численных методов, пределов сложности,
  миграций и всех языков ещё не завершён.
