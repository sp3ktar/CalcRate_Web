# CalcRate 2026.11.17.1

## Размещение

Распакуйте архив. Загрузите его содержимое в корень
репозитория GitHub Pages. Не загружайте только ZIP.

Для работы нужны:
index.html, manifest.webmanifest, sw.js,
icon-192.png, icon-512.png, icon-maskable-512.png,
apple-touch-icon.png.

Документацию и tests можно оставить в репозитории.
Серверная сборка не требуется.

## iPhone

Откройте HTTPS-адрес опубликованного сайта.
Используйте доступную в браузере команду добавления
на экран Домой. Если в используемом браузере её нет,
откройте сайт в Safari и проверьте меню Поделиться.

Дождитесь первого успешного запуска с интернетом,
затем отдельно проверьте запуск без сети.

Не удаляйте установленное приложение и данные сайта
только ради обновления: это может удалить локальные данные.

## Проверки

Фактические автоматические проверки: CHECKS.txt.
Если установлен Node.js:
node tests/engine-tests.cjs

Полная память проекта и ручной чек-лист:
PROJECT_MEMORY.md.

Эта сборка не является подтверждённо испытанным
релизом для iPhone или Windows.
